Zappos VIP is free. Members receive free expedited shipping, earn points on purchases, and can redeem points for dollar-off codes. Zappos states that members earn one point per dollar spent, with additional opportunities such as login points, review points, and brand-specific bonus points.

VIP is more useful for repeat shoppers than for someone making a single small purchase.
